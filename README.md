# Embedded Linux Device Drivers
Low-level Linux device driver and hardware abstraction examples for GPIO, I2C, SPI and UART on ARM-based platforms, with Embedded Linux BSP, device tree and kernel configuration notes for board bring-up.

Personal project based on professional embedded Linux experience (no employer code).

## Contents (planned)
- GPIO, I2C, SPI and UART driver examples
- Device tree snippets for peripheral initialization
- BSP / kernel configuration and hardware bring-up checklist
- Debugging notes: GDB, JTAG, logic analyzer, kernel logs

## Tech
C, Embedded Linux, ARM64, Device Tree, U-Boot, BSP
